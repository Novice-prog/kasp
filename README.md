# Report Export Service

Сервис для обработки текстовых файлов и формирования статистики словоформ.

---

# 🚀 Описание

Сервис принимает текстовый файл, анализирует его и формирует Excel-отчёт.

📌 Функциональность:

* загрузка текстового файла
* нормализация слов (лемматизация)
* подсчёт статистики:
  * общее количество словоформ
  * количество по строкам
* генерация Excel-файла
* асинхронная обработка через Celery

---

# ⚙️ Технологии

* Python 3.12
* FastAPI
* Celery
* Redis

# API

## 1. Загрузка файла

```http
POST /public/report/export
```

### Form-data:

* file: .txt файл

### Ответ:

```json
{
  "task_id": "..."
}
```

---

## 2. Проверка статуса

```http
GET /public/report/status/{task_id}
```

### Ответ:

```json
{
  "status": "pending | processing | done | failed"
}
```

---

## 3. Скачать результат

```http
GET /public/report/download/{task_id}
```

# 🧠 Особенности реализации

## 🔹 Асинхронность

* FastAPI НЕ обрабатывает файл
* файл отправляется в Celery
* API сразу возвращает task_id

## 🔹 Масштабируемость

* Celery обрабатывает задачи отдельно
* Redis управляет очередью

## 🔹 Оптимизация памяти

* используется `lru_cache` для лемматизации
* статистика хранится в разреженном виде

## 🔹 Работа с большими файлами

* чтение файла чанками
* отсутствие загрузки в память целиком

## 🔹 Lifecycle файлов

* upload удаляется после обработки
* результаты очищаются по TTL
